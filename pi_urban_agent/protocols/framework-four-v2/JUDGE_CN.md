# 独立功能评分（准备版）

输入仅含匿名后的自然对话、代码/结果/必要执行证据、测试者交流机会日志。先判断证据充分性。不要因系统自称Planner/Reviewer、创建Tree或某个工具名而给分。不要读取其他条件评分；不继承测试者或执行者上下文。

每项0/1/2：0未完成或证据矛盾，1部分完成，2证据充分地完成。每项必须列出具体轮次、产物位置及理由。无法判断标记unverifiable，不臆测。

1. **方案合理性**：尺度及模型选择有理由、符合实际数据与预算；不按尺度/节点数量给分。
2. **执行完成与可比性**：完成实际获批范围，保持变量与研究口径一致，有脚本和真实结果；必须覆盖OLS和可行GWR比较，不能靠只做最简单一项得满分。
3. **带宽追问响应**：理解固定距离/自适应区别，执行可行且已授权的补充，或用证据说明不可行并寻求合理调整。无法估计不能等同于完成比较；分别记录解释与执行。
4. **人类修改落实**：针对实际存在的目标正确更新决定、后续行动和结论；保留未受影响结果，不能只口头答应。
5. **检查与纠错**：对真实代码/结果作有依据的核查，有错则修正；没有错误不强求制造错误，也不要求独立Reviewer出场。
6. **规律与城市意义**：从实际结果提炼跨尺度稳定性/变化，有具体数值或地图依据；不要求预设方向，不将拟合度最大直接当最优尺度。
7. **状态恢复与证据回查**：准确区分执行/计划、当前决定和下一步，数值可追溯；按本次真实路线判，不按固定四条判。

另列：机会是否全部提供；测试者是否额外救援；自然压缩是否真的发生；授权范围及完成范围；委派次数（仅描述）；失败类别。未触发压缩的轨迹不支持压缩后恢复结论。

完整成功：所有实际授权的必要分析和修改均完成，核心事实可核查，未执行工作未被冒充完成。给出独立判定理由，不仅凭进程exit=0或总分阈值。耗时与token包含子智能体和压缩调用，缺失用null，不填0。不要用全局40%上限。
