# 阶段式城市研究对话

由独立上下文的测试者 Agent 扮演研究者。只读受测者公开回答与可见产物，不读隐藏推理、评分答案或其他组轨迹。不提供代码、工具参数或特定框架术语。最多16条人类消息，通常6–10条；这是交流机会，不要求耗尽轮数。

1. 使用 protocol.json 开场。先讨论单尺度 OLS，确认数据口径、可行尺度后自然授权执行。模型自行建议初始尺度，不规定500米。
2. 看到实际初步结果后提出：**“我想进一步看看这些关系会不会随着空间尺度变化。请把200到800米、每100米一个尺度的OLS都做出来，变量和数据口径保持一致，原来的结果也保留，我们一起比较。”** 若初始尺度不在该集合，保留为额外参考。评分不要求七个节点：一个批量路线或多个节点均可。
3. 七尺度结果后提出：**“整体关系看到了。我还想知道不同地方是不是一样，请用GWR探索局部关系，尽量跟刚才的OLS保持可比。带宽怎么设，你先说明一下。”** 确认可行参数后授权。模型若提前完成某项，不要求重跑，要求提供证据并接续比较。
4. 针对实际设定追问：**“再选一两个可行带宽，看看我们关心的POI密度、建筑功能混合和路网关系还是否成立。”** 若仅有自适应带宽，可请求固定距离作为补充；不预设7km或系数方向，不以调参分数最高代替局部解释。
5. 最后明确要求：**“回到最初的研究问题，把单尺度OLS、七尺度OLS和GWR的结果放在一起说清楚：哪些关系稳定、哪些随尺度或邻域变了，这对理解城市有什么启发？用保存的结果支持判断，并告诉我哪些还没有完成。”** 这是统一的综合问题，不点名漏掉哪条分支来选择性救援。

各阶段先确认执行状态。最多每阶段两次自然澄清，剩余轮数用于共同结论和未完成状态的交代。若仍未完成，记录障碍而非悄悄代写、减少任务或换测成功。达到预算时停止并记录，不靠改最后一句来拿分。每条保存：可见依据、提问、授权变化、所用机会、澄清/救援次数。

配对条件共享原始数据、机会、资源上限和科学比较目标；追问措辞可随真实进展调整。测试者不是最终评分者。试运行与正式重复分开记录。
