# 五维评价及跨分支总结

评审在独立上下文中看匿名对话、脚本、实际输出及执行凭据，不读框架标签和其他评分。只有前三项/第四项按0未完成或矛盾、1部分、2充分进行分项判断；成本报告实数，不纳入“越便宜越好”的总分。

1. **分析交付**：授权的单尺度OLS、七尺度OLS、GWR和额外带宽是否真正执行；聚合支持、变量口径及计算是否一致。脚本存在不等于运行成功。
2. **人类调整落实**：单尺度→七尺度→局部探索是否落实到后续分析；未受影响证据是否仍可使用。不限树或文件实现，不强求撤销一次批准。
3. **研究状态一致性**：所说“已完成/计划/待检验”是否与实际过程一致；当前授权与遗留问题是否准确。只有具体矛盾才能判执行过程幻觉；遗漏与捏造分别记录。
4. **解释与证据对应**：解释的数值、变量、符号、尺度、带宽及单位是否有对应产物支持。输出正确不能抵消错误解释。记录事实错误、遗漏、合理但待检验的城市机制假设，三者不要混判。
5. **运行成本**：全流程及最终综合阶段的耗时、输入/输出/缓存token、工具数、子Agent及摘要请求；缺失值为null。另报任务实际完成范围、预算触顶与中断。

为检验“是否关注新结果而遗漏旧结果”，对每次运行建立证据清单：单尺度OLS、跨尺度OLS、GWR空间差异、带宽敏感性。分别标记未交付/已交付未使用/准确使用/错误使用。对已交付且与最终问题相关的材料计算证据覆盖率，同时报告四类完整任务覆盖，防止只交一项也得100%。最终论断逐条绑定产物定位，由独立计算核查可核查的数值；合理城市解释以与证据相容、有明确空间含义为标准，不以与作者文字相似为标准。
